# OE-FRP – Hallgatói jelentkezés

Az Óbudai Egyetem **Fejlett robotprogramozás ROS környezetben** tantárgyának GitHub organizationje.

Az organization a kötelező programok és hallgatói projektek repositoryjainak kezelésére szolgál.

**[Kurzus honlapja – Tananyagok és követelmények](https://abc-irobotics.github.io/advanced_ros_course_materials_hu/)**

## Csatlakozás

1. Nyisd meg a **[Jelentkezési űrlapot](https://github.com/OE-FRP/jelentkezes/issues/new/choose)**.
2. Válaszd ki a gyakorlati csoportodat (FRP1 / FRP2).
3. Küldd be a jelentkezést.
4. Az oktatói jóváhagyást követően fogadd el a GitHub organization meghívóját.

## Kötelező programok

- A kötelező programokat **private repositoryban** kell elkészíteni az `OE-FRP` organizationön belül.
- A repository elnevezésére és a beadási határidőkre a kurzus honlapján közzétett követelmények vonatkoznak.
- A repositorykat az oktatók ellenőrzik és értékelik.

**Fontos:** A jelentkezések nyilvánosak, ezért Neptun-kódot vagy más személyes adatot ne adj meg az űrlapon.
